# Plan type: Missed AC

## 1. What makes it Missed AC

- **Shipped work didn't meet its own ticket's AC.** The code does what it was written to do, so it isn't a Bug. YouTrack usually files it as a Bug.

## 2. Requirement

- **The original ticket's AC.** Find the original ticket from the missed-AC ticket's links or text, or from the history of the shipped code: `/eli--file-history` traces a commit to its ticket. Read it with `/eli--read-ticket`. The missed-AC ticket says which part of the original the shipped work missed.

## 5. Steps and stops

- **Make the code changes, then the closing stops.**
