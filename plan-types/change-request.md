# Plan type: Change request

## 1. What makes it a Change request

Shipped work met its AC, and the business now wants something different. The code does what it was written to do, so it isn't a Bug. YouTrack often files it as a Bug.

## 2. Requirement

The new ask, as the ticket or the product owner states it.

## 5. Steps and stops

Make the code changes, then the closing stops.
