# Release Schedule

Beta is cut from `development` every Tuesday. Beta goes to prod every Friday. Code merged Wednesday through the following Tuesday morning reaches beta that Tuesday and prod that Friday. The schedule almost never slips. The exceptions are hotfixes and a rare skipped release week, such as Thanksgiving. For code already shipped, confirm the date from its arrival on `origin/master` (`swyfft-domain.md` § "Branch-to-Environment Mapping").
